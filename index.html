Claude Fable 5.2 & Mythos 5.2: Neue Flaggschiff-Modelle mit 2,5× Fast Mode

Anthropic hat am 9. November Claude Fable 5.2 und das Restricted-Access-Modell Claude Mythos 5.2 eingeführt – die bisher leistungsfähigsten Claude-Modelle für anspruchsvolle technische Aufgaben. Anthropic setzt strenge Sicherheitsregeln für Claude-Hardwaresteuerung – in Kraft ab 12. November

Anthropic veröffentlicht eine neue Policy: Ab dem 12. November gelten strenge Sicherheitsauflagen für alle Anwendungen, bei denen Claude physische Hardware steuert – von Robotern bis zu industriellen Systemen. Die Richtlinie schreibt unter anderem Human-in-the-Loop-Anforderungen, explizite Freigaben für irreversible Aktionen und detailliertes Logging vor. Anthropic reagiert damit präventiv auf regulatorischen Druck, noch bevor externe Vorgaben greifen.

Präventive Governance: Anthropic handelt, bevor etwas schiefgeht – Hardware-Kontrolle durch KI ist eine der kritischsten Sicherheitsfronten der nächsten Monate.

Sicherheit Microsoft AI Agents 10. Nov. 2026

Microsoft-Warnung: Agentische KI nutzt GitHub-Leaks – Azure Key Vaults in Minuten kompromittiert

Microsoft hat eine kritische Sicherheitswarnung veröffentlicht: Agentische KI-Systeme, die auf geleakte GitHub-Credentials zugreifen, können innerhalb von Minuten in Azure Key Vaults eindringen und von dort auf weitere Cloud-Ressourcen eskalieren. Der Angriffspfad – geleakter GitHub-Token → Azure-Zugangsdaten → Key Vault-Secrets → Cloud-Infrastruktur – wurde in einem Red-Team-Szenario demonstriert. Microsoft empfiehlt dringend Managed Identities statt manuell verwalteter Credentials sowie automatische Secret-Rotation. Besonders brisant: KI-Tools wie Claude Code können Konfigurationsdaten in öffentliche Repos exponieren.

Handlungsbedarf: GitHub-Repos auf geleakte Credentials scannen, Managed Identities einsetzen und .claude/ in .gitignore aufnehmen.
