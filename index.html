Fast Mode Opus 4.7 Cache Diagnostics

Claude Developer Platform: Fast Mode für Opus 4.7 (Research Preview) & Cache Diagnostics in Public Beta

Anthropic hat zwei neue Features auf der Developer Platform released. Fast Mode für Claude Opus 4.7 (Research Preview): Signifikant schnellere Output-Token-Generierung für das leistungsstärkste Claude-Modell – bisher exklusiv in Claude Code, jetzt auch über die API verfügbar. Cache Diagnostics (Public Beta): Die API erklärt jetzt konkret, warum ein Prompt-Cache-Miss aufgetreten ist – z. B. weil Inhalte geändert wurden oder Cache-Grenzen überschritten wurden. Entwickler-Impact: Cache Diagnostics macht Prompt-Caching endlich transparent – bislang war es oft rätselhaft, warum der Cache nicht griff und man die vollen Token-Kosten zahlte.

Claude Code Agent View Auto Mode

Claude Code: Agent View & Auto Mode – mehrere Sessions verwalten, kaum noch Unterbrechungen

Anthropic hat zwei neue UX-Features für Claude Code ausgerollt. Agent View: Eine neue CLI-Übersicht, die mehrere Agent-Sessions gleichzeitig verwaltet – Agents starten, in den Hintergrund senden, Status und letzte Antworten prüfen, nur bei Bedarf eingreifen – alles aus einer Ansicht. Paradigmenwechsel: Claude Code wird zum echten Hintergrundarbeiter – weniger interaktiver Gesprächspartner, mehr autonomer Entwickler-Assistent der einfach liefert.

Novo Nordisk & OpenAI: KI durch den gesamten Pharma-Prozess – von Wirkstoffentdeckung bis Supply Chain bis Ende 2026
