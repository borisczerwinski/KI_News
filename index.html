Claude Code Skills-Sicherheit MCP 2026-07-28 OAuth / OIDC

Claude Code härtet Skills gegen Missbrauch – MCP-Spec 2026-07-28 mit OAuth 2.0, OIDC und Observability

Claude Code hat die Behandlung von Skills aus claude.ai grundlegend gehärtet: Skills überschatten keine lokalen Befehle oder MCP-Prompts mehr, ihre Beschreibungen werden bereinigt und gekennzeichnet, und auf dem eigenen Rechner dürfen Skill-Bodies keine Shell-Befehle ausführen oder @-Dateien expandieren. Das schließt eine Klasse von Prompt-Injection-Vektoren. Parallel tritt die neue MCP-Spec 2026-07-28 in Kraft: stateless Kern, robustes OAuth 2.0 und OIDC, versionierte Extensions für Apps und Tasks sowie neue Connector-Features wie eingebettetes UI, Enterprise-managed Auth, Observability und Private-Network-Tunnel.

Security first: Die Skills-Härtung macht Claude-Workflows produktionstauglich für Unternehmensumgebungen. MCP 2026-07-28 setzt den Standard für sichere Agenten-Protokoll-Kommunikation.

DARPA F-16 vollständig KI Erster Realflug ohne Pilot Autonome Systeme

DARPA-Meilenstein: Erster Realflug eines F-16 vollständig von KI gesteuert – kein Pilot an Bord

Die US-amerikanische DARPA hat den ersten echten Flug eines F-16-Kampfjets abgeschlossen, der vollständig von Künstlicher Intelligenz kontrolliert wurde – ohne Pilot. Der Meilenstein markiert eine neue Ära autonom fliegender Militärsysteme. Die KI übernahm alle Flugmanipulationen in Echtzeit, einschließlich Ausweichmanöver und Lagekorrekturen. Das Projekt baut auf DARPAs Air Combat Evolution (ACE)-Programm auf, das seit 2020 KI-gesteuerte Luftkampf-Agenten trainiert. Der Erfolg erhöht den Druck auf NATO-Partner, eigene autonome Luftsysteme zu entwickeln. Kritiker warnen vor einem KI-Wettrüsten in der militärischen Automation.

Paradigmenwechsel: Vollautonome Kampfflugzeuge sind kein Science-Fiction mehr. Der Realflug schließt die Lücke zwischen Simulation und echtem Einsatz – mit weitreichenden geopolitischen Implikationen.
