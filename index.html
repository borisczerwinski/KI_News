🔴 Heute in Kraft Billing Split Agent SDK • GitHub Actions Handlungsbedarf

Anthropic Billing Split ab heute: Separate Monthly Credits für Agent SDK & GitHub Actions – Pro $20 • Max 5x $100 • Max 20x $200

Ab dem 15. Juni 2026 trennt Anthropic die Abrechnung für programmatische Nutzung vom interaktiven Chat. Claude Agent SDK, der claude -p-Befehl, Claude Code GitHub Actions und Drittanbieter-Apps über den Agent SDK verbrauchen nun einen separaten Monthly Credit – $20 für Pro, $100 für Max 5x, $200 für Max 20x. Der Credit muss einmalig beansprucht werden, setzt sich mit jedem Billing-Zyklus zurück und verfällt nicht übertragbar. Interaktive Nutzung (Claude.ai Chat, Terminal Claude Code) ist nicht betroffen. Wer keinen Credit beansprucht oder das Limit überschreitet, erhält API-Fehler – automatisierte Workflows können abreisßen.

Sofort handeln: Claim-E-Mail von Anthropic öffnen, Credit einlösen und „Usage Credits“ aktivieren – damit automatisierte Workflows auch nach Credit-Erschöpfung weiterlaufen können.
