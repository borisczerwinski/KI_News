Anthropic launcht Claude Fable 5.1 & Mythos 5.1: 52,6 % auf Terminal-Bench-Science, 75 % günstigere Cache-Reads, per-Message-Effort-Control und Content-Provenance-Wasserzeichen

Anthropic veröffentlicht am 1. September 2026 zwei neue Modelle: Claude Fable 5.1 (allgemein verfügbar) und Claude Mythos 5.1 (für geprüfte Cybersecurity- und Life-Sciences-Nutzer). Beide sind dasselbe Basismodell mit unterschiedlichen Safeguard-Regimes. Die Schlagzeile: 52,6 % auf Terminal-Bench-Science 0.1 – gegenüber 24,7 % für Fable 5 und 29,0 % für Opus 5. Drei Breaking Changes: Forced Tool Use gibt jetzt einen Error zurück, frühere Modelle können keine Thinking-Blocks lesen, und das Bearbeiten früherer Turns invalidiert Thinking-Blocks.

Mehr als doppelt so stark bei Science: 52,6 % vs. 24,7 % auf Terminal-Bench-Science ist kein inkrementeller Fortschritt – das ist ein Generationssprung für Coding-Agenten und wissenschaftliche Recherche. Dazu 75 % günstigere Cache-Reads.

CVE-2026-54316 Claude Code GitHub Action Wasserzeichen

Sicherheitslücke in Claude Code GitHub Action (CVE-2026-54316): CI-Runner-Secrets können ausgelesen werden – plus neues Content-Provenance-Wasserzeichen in allen Modellen ab August 2026

Ein Sicherheitsforscher hat demonstriert, dass ein einzelnes GitHub Issue über einen Prompt-Injection-Angriff CI-Runner-Secrets aus offiziellen Repos von Anthropic, Google und OpenAI exfiltrieren kann. Die Schwachstelle in Claude Code’s GitHub Action ist als CVE-2026-54316 registriert; parallele CVEs treffen Gemini CLI und OpenAI Codex. Anthropic empfiehlt Nutzern, die Claude Code in GitHub Actions einsetzen, umgehend zu patchen und Secrets zu rotieren. Auf der anderen Seite des Sicherheitsspektrums: Alle Claude-Modelle, die nach dem 2. August 2026 veröffentlicht wurden (einschließlich Fable 5.1 und Mythos 5.1), erhalten nun ein statistisches Wasserzeichen (Content Provenance), das die Wahrscheinlichkeit anzeigt, dass ein Text von Claude verfasst wurde – im Einklang mit dem EU AI Act Code of Practice.

Zwei Seiten von KI-Sicherheit: Der CVE zeigt, wie angreifbar agentic­e Pipelines sind – Prompt Injection bleibt das größte Risiko für CI/CD-Integrationen. Das Wasserzeichen zeigt, dass Anthropic gleichzeitig an Transparenz-Standards arbeitet.

Bitkom 2026 41 % nutzen KI KMU Deutschland

Bitkom-Studie 2026: 41 % der deutschen Unternehmen nutzen KI aktiv – Verdoppelung gegenüber 2025. KMU automatisieren doppelt so viel, 77 % berichten von verbesserter Wettbewerbsposition

Die neue Bitkom-Studie 2026 zeichnet ein klares Bild: 41 % der deutschen Unternehmen ab 20 Mitarbeitenden setzen KI aktiv ein – ein massiver Sprung gegenüber 17 % im Vorjahr. Weitere 48 % planen oder diskutieren den Einsatz. Besonders bemerkenswert ist die Entwicklung bei Kleinstunternehmen: 34 % automatisieren bereits Prozesse mit KI (2025: 16 %). Laut Simon-Kucher-Studie wirkt KI spürbar auf Produktivität und Beschäftigung ab einem Automatisierungsgrad von rund 30 %. Die messbaren Effizienzgewinne: bis zu 80 % kürzere Durchlaufzeiten bei automatisierten Prozessen und bis zu 90 % weniger manuelle Fehler in der Datenverarbeitung. 77 % der deutschen KI-Nutzer berichten von einer verbesserten Wettbewerbsposition.

Wendepunkt erreicht: Von 17 % auf 41 % in einem Jahr – das ist kein lineares Wachstum mehr, das ist ein Adoption-Kipp. Unternehmen, die noch zuwarten, werden in weniger als zwei Jahren gegen KI-augmentierte Wettbewerber antreten.
