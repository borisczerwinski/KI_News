Agentjacking Neue Angriffsklass Markdown-Injection Coding-Agenten

Neue Angriffskategorie „Agentjacking“ entdeckt: Fake-Sentry-Fehlermeldungen schleusen Markdown-Injection in KI-Coding-Agenten

Sicherheitsforscher haben im Juni 2026 eine neue Angriffskategorie namens Agentjacking offengelegt. Angreifer erstellen gefälschte Sentry-Fehlermeldungen mit eingebettetem Markdown, das KI-Coding-Agenten als legitime Debugging-Anweisung interpretieren. Da viele Agenten wie Claude Code oder GitHub Copilot Sentry-Logs direkt auslesen, können Angreifer dadurch beliebige Befehle in den Agenten-Workflow einschleusen – von der Änderung von Quellcode bis zum Exfiltrieren von Geheimnissen. Die Schwachstelle betrifft alle Agenten, die externe Monitoring-Daten ohne Sanitisierung verarbeiten. Erste Patches werden von betroffenen Plattformen bereitgestellt.

Supply-Chain-Risiko für KI-Agenten: Je mehr Agenten externe Datenquellen lesen, desto größer die Angriffsfläche – Agentjacking zeigt, dass klassische Injection-Angriffe in der KI-Ära eine neue Dimension bekommen.
