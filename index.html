Claude Code Mods TypeScript 1. Okt. 2026

Claude Code Mods: TypeScript-Plugins verändern, wie Claude Code funktioniert – Prompts umschreiben, Tools blockieren, eigene UI einbauen

Anthropic hat Mods für Claude Code eingeführt – kleine TypeScript-Funktionen, die das Verhalten von Claude Code grundlegend verändern. Mods können Prompts vor der Modellübergabe umschreiben, riskante Tool-Aufrufe blockieren oder mit Retry versehen, eigene UI-Komponenten in CLI und Desktop-App einbetten sowie Berechtigungsanfragen automatisch genehmigen oder ablehnen. Mods funktionieren als Event-Handler: Claude Code ruft sie bei Ereignissen wie Tool-Aufrufen, eingereichten Prompts oder UI-Rendering auf. Das eingebaute Mod „You should know“ beobachtet Aktionen und weist auf Dinge hin, die Claude oder die Nutzenden übersehen könnten. Mods werden über Plugins ausgeliefert und können über das Claude-Verzeichnis oder per /plugin-Befehl installiert werden.

Claude Code wird zur Plattform: Mods machen Claude Code zum erweiterbaren Werkzeug – Teams können firmeneigene Sicherheitsregeln, Secret-Redaktion oder Custom-UI einbauen, ohne auf Anthropic warten zu müssen. Das ist ein Paradigmenwechsel vom Tool zur Plattform.

Claude Code Projects Parallele Threads Beta Okt. 2026

Claude Code Projects Redesign: Ein Koordinator steuert parallele Agenten-Threads – gemeinsamer Speicher, automatisches Delegieren

Anthropic hat Projects in Claude Code komplett neu gedacht. Was früher ein statischer Ordner für Instruktionen war, ist jetzt ein konversationeller Koordinator, der autonome Aufgaben an mehrere parallele Agenten-Threads delegiert. Der Nutzer beschreibt das Ziel – Claude unterteilt die Arbeit, weist Threads zu, überwacht den Fortschritt und führt Ergebnisse zusammen. Jeder Thread läuft als eigenständige Claude Code Cloud Session mit separater Repository-Kopie und eigenem Branch. Dazu kommt eine gemeinsame Project Library für Entscheidungen, Ppläne und Fortschritt – kein manuelles Handoff mehr zwischen Sessions.

Vom Tool zum Agenten-Orchester: Das neue Projects macht Claude Code zum echten Multi-Agent-System – komplexe Projekte werden parallel bearbeitet, der Mensch gibt nur noch die Richtung vor. Die Beta startet für ausgewählte Pro- und Max-Abonnenten.

Claude Tag: Persönliche Konnektoren in Slack-Channels – Review- oder Auto-Modus & stärkere Enterprise-Governance

Claude Tag erweitert seine Beta um persönliche Konnektoren in Slack-Channels. Supabase $150M Series D Turso Akquisition Okt. 2026

Supabase sammelt $150 Mio. ein und übernimmt Turso: KI-Agenten-Infrastruktur mit Embeddings & gehosteten Sandboxes

Supabase hat eine Series-D-Runde über $150 Millionen abgeschlossen und gleichzeitig Turso übernommen, um seine Infrastruktur für KI-Agenten massiv auszubauen. Turso bringt leichtgewichtige SQLite-Datenbankinstanzen mit, die sich ideal für agentic Workloads eignen: Pro Agent können eigene Datenbankinstanzen mit niedrigen Latenzzeiten bereitgestellt werden. Supabase erweitert damit sein Angebot um Embeddings, Vektor-Suche und gehostete Sandboxes für reproduzierbare, isolierte Agenten-Ausführung. Die Kombination aus Postgres-kompatiblem Backend, Realtime-Features und jetzt agentic Infrastruktur macht Supabase zur bevorzugten Entwicklerplattform für KI-Apps.

KI-Agenten brauchen Infrastruktur: Supabase setzt auf den nächsten Infrastruktur-Boom. Wer Agenten deployed, braucht isolierte Sandboxes, Vektordatenbanken und schnelle Datenbankinstanzen – genau das liefert Supabase jetzt out-of-the-box.
