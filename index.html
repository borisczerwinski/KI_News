CVSS 10.0 Kritisch Google Cloud ADK CVE-2026-79696 Remote Code Execution Patch erforderlich

Kritische Sicherheitslücke im Google Cloud AI Agent Development Kit (CVSS 10.0): Unauthentifizierte Remote-Code-Ausführung – Patch für Python-Versionen 2.0.0–2.6.0 dringend erforderlich

Am 9. September 2026 wurde CVE-2026-79696 mit einem CVSS-Score von 10.0 – der höchstmöglichen Bewertung – für Googles Agent Development Kit (ADK) für Python veröffentlicht. Die Schwachstelle betrifft die Versionen 2.0.0 bis 2.6.0 und ermöglicht es einem nicht authentifizierten Remote-Angreifer, über eine manipulierte Test-Session-Replay-Anfrage beliebigen Code auf dem Zielsystem auszuführen. Da der ADK weit verbreitet für den Aufbau produktiver KI-Agenten-Systeme auf Google Cloud verwendet wird, ist das Angriffspotenzial enorm. Alle betroffenen Systeme sollten sofort auf die gepatchte Version aktualisiert werden. Bis zum Patch sollten ADK-Instanzen nicht öffentlich zugänglich sein. Diese Schwachstelle unterstreicht die wachsenden Sicherheitsherausforderungen im KI-Agenten-Ökosystem.

Sofortiger Handlungsbedarf: CVSS 10.0 bedeutet maximale Kritikalität – wer Googles Agent Development Kit einsetzt, muss jetzt patchen. Die Schwachstelle zeigt: KI-Agenten-Frameworks brauchen dringend striktes Security-Testing.
