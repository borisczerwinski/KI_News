Anthropic Security Distillation 14. Okt. 2026

Anthropic blockiert Distillation-Angriffe zu 90–99 %: Schutz gegen Modell-Diebstahl via Proxy

Anthropic hat neue Sicherheitsmaßnahmen gegen Distillation-Attacken veröffentlicht, die den Zugriff auf geschützte Denkprozesse (Chain-of-Thought) über Proxy-Netzwerke drastisch einschränken. Laut dem Bericht blockt das System 90 bis 99 % aller Angriffe dieser Art. Hintergrund: Chinesische Start-ups sollen zuvor systematisch Daten aus Claude über Proxy-Routen abgegriffen haben, um eigene Modelle zu trainieren (sogenanntes Model Stealing). Anthropic reagiert damit auf einen wachsenden Markt für illegitime Modell-Destillation, bei der Frontier-Modelle als unentgeltliche Lehrmodelle missbraucht werden. Das Cyber Verification Program bietet darüber hinaus legitimierten Sicherheitsforschern gestaffelte Zugangsebenen.

IP-Schutz wird zur Kernkompetenz: Wer Frontier-Modelle baut, muss sie auch schützen. Anthropics Lösung könnte Industriestandard für Modell-IP-Sicherheit werden.

OpenAI “Dots”: Always-On-Agenten, die zwischen Gesprächen weiterarbeiten – powered by GPT-6 Astra

OpenAI hat das Produkt Dots eingeführt: persistente KI-Agenten, die auch zwischen Nutzer-Sessions aktiv bleiben und kontinuierlich an Zielen weiterarbeiten. Von reaktiv zu proaktiv: Dots markiert den Übergang – KI-Assistenten werden zu dauerhaft aktiven digitalen Mitarbeitern. Ein fundamentaler Wandel im Mensch-Maschine-Verhältnis.
