MCP Spec 2026-07-28 🔥 Heute live Stateless Core Tasks + MCP Apps

Historische MCP-Spec-Revision live: Stateless, Tasks Extension, MCP Apps – und kompletter Auth-Neustart mit OAuth/OIDC

Heute, am 28. Juli 2026, veröffentlicht die MCP-Community die größte Revision des Model Context Protocol seit seinem Launch. Die Kernänderung: MCP wird vollständig stateless. Sessions und Initialization-Handshake werden abgeschafft – ein Remote-MCP-Server läuft jetzt hinter einem einfachen Round-Robin-Load-Balancer ohne Session-Stores oder Sticky-Sessions. Zwei neue Erweiterungen folgen: die Tasks Extension für lang laufende Hintergrundarbeit (z. B. stundenlange Agenten-Workflows) und MCP Apps für server-gerenderte UIs direkt im Client. Die Authentifizierung wird auf OAuth und OpenID Connect umgestellt und vereinfacht Enterprise-Deployments drastisch. Bestehende Features bleiben 12 Monate abwärtskompatibel, aber LangGraph 1.0 behandelt MCP-Tools bereits als First-Class-Nodes – die Migration sollte jetzt beginnen.

Das neue Fundament der Agenten-Ära: Stateless MCP skaliert auf normaler HTTP-Infrastruktur – jeder Hoster kann jetzt ein MCP-Server sein, ohne spezielle Session-Infrastruktur.
