Anthropic Haiku 5.5 Neues Modell 7. Okt. 2026

Claude Haiku 5.5: Das schnellste, günstigste Claude-Modell mit 1 Mio. Token Context Window und adaptivem Denken

Anthropic hat Claude Haiku 5.5 (claude-haiku-5-5) veröffentlicht – das aktuell leistungsfähigste kleine Modell des Unternehmens, optimiert für hochvolumige und latenzsensitive Anwendungsfälle. Haiku 5.5 bietet ein 1-Millionen-Token-Context-Window, bis zu 128 000 Max-Output-Tokens und adaptives Denken über den effort-Parameter – ein Feature, das bisher Spitzenmodellen vorbehalten war. Das Modell ist auf der Claude API, Amazon Bedrock, Google Cloud und Microsoft Foundry verfügbar. Parallel wurde der Cache-Preis für Sonnet 5.5 am 7. Oktober auf $0,10 pro Million Tokens gesenkt. Laut Anthropic bewältigt Haiku 5.5 die meisten Alltagsaufgaben wie ein Spitzenmodell – aber zu Einstiegskosten.

Kleine Modelle holen auf: 1M Context, adaptives Thinking und Multi-Cloud-Support bei einem „kleinen“ Modell – das verschiebt die Wirtschaftlichkeit von KI-Anwendungen grundlegend. Was gestern ein Flaggschiff-Feature war, ist heute im Basisangebot.

Claude Code 2.1.292 Mods & Plugins Okt. 2026

Claude Code 2.1.292: TypeScript-Mods, neue Plugin-API, parallele Projects und Security-Fixes

Release 2.1.292 bringt die wichtigste Architekturänderung von Claude Code seit Langem: Claude Code Mods sind kleine TypeScript-Funktionen, die das Verhalten des Assistenten anpassen – von benutzerdefinierten Workflows über Validierungsregeln bis zu Team-Policies. Mods werden in Plugins ausgeliefert und können über das Plugin-Directory geteilt werden. Projects wurden als Beta neu gestaltet: Ein Projekt koordiniert parallele Threads, gemeinsamen Speicher und eine Projekt-Bibliothek. Weitere Neuerungen: verwaltete Agents-Integration, reichere Plugin- und Hook-Metadaten, neue Session- und Log-Shortcuts, VS Code-Workflow-Upgrades und wichtige Sicherheitsfixes inkl. behobener Regressionen beim Session-Verlust.

Claude Code wird zur Plattform: Mit Mods und Plugin-Directory entsteht ein Ökosystem rund um Claude Code. Teams können eigene Verhaltensregeln paketieren und teilen – der Beginn eines Marketplace-Modells für KI-Entwicklungstools.

Claude FinTech Slack Tag Okt. 2026

Claude for Financial Advisors, Slack Tag mit Connectors und Compliance API: Anthropics Enterprise-Offensive

Anthropic baut seine Enterprise-Plattform auf breiter Front aus: Claude for Financial Advisors ist ein branchenspezifisches Plugin mit geplanter Schwab-Datenanbindung, das Finanzberatern bei Portfolioanalyse und Kundenberatung helfen soll. Mistral Large 4: Stärkstes offenes KI-Modell aus Europa erreicht Weltklasse-Niveau
