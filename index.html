Neu Managed Agents Agent SDK Claude Code

Claude Managed Agents: 3 neue Features – Dreaming, Multiagent Orchestration & Outcomes – plus Code w/ Claude London & Tokyo

Anthropic hat Claude Managed Agents auf der Claude Platform mit drei neuen Features aktualisiert, die Teams beim Aufbau und Betrieb von Cloud-Agenten in großem Maßstab unterstützen. Dreaming lässt Agenten vergangene Sessions überprüfen, Muster erkennen und Memory automatisch verbessern – wiederkehrende Fehler und Teampräferenzen fließen direkt in den Wissensstand ein. Multiagent Orchestration erlaubt einem Lead-Agenten, spezialisierte Subagenten parallel auf einem gemeinsamen Filesystem einzusetzen, jeder mit eigenem Modell, Prompt und Tools – vollständig in der Claude Console nachvollziehbar. Outcomes definiert eine Bewertungsrubrik: Ein separater Grader-Agent prüft jedes Ergebnis und schickt den Agenten bei Bedarf zur Überarbeitung zurück – bis zu 10 Punkte Verbesserung auf internen Benchmarks. Zusätzlich: Claude Code erhält eine neue Agent View für Multi-Session-Management aus einer einzigen CLI-Ansicht.

Code w/ Claude Events: London 20.–21. Mai und Tokyo 5. Juni – Anthropic zeigt live, wie Teams auf dem KI-Exponential aufbauen.
